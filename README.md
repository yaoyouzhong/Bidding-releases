# 标书工作台

面向 Windows 的本地标书检查与材料整理工具，支持企业和人员资料、投标文件检查、多公司文件查重，以及人工复核与交付归档。

## 安装与更新

适用于 Windows 10/11 x64。普通用户推荐安装 `Biaoshu_0.3.0_x64-setup.exe`，保留默认安装位置即可使用应用内更新。需要集中部署时选择 `Biaoshu_0.3.0_x64.msi`；机器级安装通过新版安装包手动升级。两者择一，无需另装 Python、Node 或 Rust。

本版已带自动检查更新功能。发现新版后，应用设置显示提醒；查看版本说明、保存编辑并确认后，点击“一键升级”即可下载、校验、安装并重启。升级失败时尝试恢复旧版。任务运行期间不能安装更新；涉及数据库结构变化的版本使用另行验证的完整安装包。

程序使用 Microsoft Edge WebView2，首次安装建议保持联网。企业信用与学历官网查询需要本机安装 Google Chrome，遇到需要人工完成的验证时按官网提示操作。

首次启动后建立投标人和项目，再导入材料。核对原件、处理问题后进行终审与归档；机器检查结果是复核线索，归档不代表已递交。

安装包尚未取得 Windows Authenticode 签名，可用同版 `SHA256SUMS.txt` 核对完整性；应用内更新另外使用程序内置公钥验证更新包签名。

## 数据与 AI

资料默认保存在本机。AI 增强默认关闭，配置模型并明确开启相应用途后才发送相关内容。请备份重要资料；公开反馈问题时不要附真实投标材料、身份证件、数据库或密钥。
