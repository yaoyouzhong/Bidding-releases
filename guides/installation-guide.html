标证 0.4.7 · 下载安装

本次发布 0.4.7：完善人员目录、多文件导入与逐项核对，修复资料分类和姓名关联，改善批量选择与简历生成反馈。简历附件支持清晰压缩或保留原图。安装包约 116.3 MiB，不内嵌识别模型；已有匹配缓存继续复用，新电脑可下载或离线导入模型。Gitee 提供四卷手动安装，应用内更新仍需下载 GitHub 完整 EXE。

1. 下载程序

Windows 10/11 x64。Gitee 国内下载页：下载 .001、.002、.003、.004 四卷，以及 install.cmd、merge-install.ps1、split-installer.json，放进同一可写文件夹，文件名保持原样。每卷不超过32 MiB。不要下载 Source code 作为安装器。

GitHub 完整 EXE：只需下载 Biaoshu_0.4.7_x64-setup.exe（121,923,933 字节）。SHA-256：5c0c352868c16356317a452243877b98bb9f5b0de68b39d8164e76ca3035c11f。

2. 安装或升级

保存工作，结束任务并退出旧程序。Gitee 用户双击 install.cmd；它会校验每卷、合并并校验完整 EXE 后启动安装。缺卷或损坏时停止，不得绕过。GitHub 用户直接运行完整 EXE。不要运行分卷。

跟随向导安装，旧版建议沿用原目录。首次安装建议联网准备 WebView2；无需另装 Python、Node 或 VC++ 运行库。打开程序，核对版本 0.4.7。安装器暂无 Windows 发布者签名，请先确认官方来源；不要关闭系统安全防护。

3. 准备识别模型

本版不内嵌模型。已有匹配缓存显示就绪时无需重复下载。新电脑打开“应用设置 → 本地识别模型”，下载缺失项；或在独立模型页下载 models-document-v1.zip 与按需使用的 models-captcha-v1.zip，在程序内导入，无需手动解压。模型就绪后可本地识别。

4. 后续更新

应用内更新目前需要 GitHub 完整 EXE；国内分卷手动安装可用，不代表已实现国内分卷自动更新。0.4.1及以前版本需手动安装新版一次。备份与原件继续保留；升级前建议保留独立备份。

遇到问题

缺卷：重新下载缺项；哈希不符：重新下载对应卷，勿运行损坏文件。打不开：按提示完成 WebView2 准备。模型缺失：核对模型类别与具体错误后重试。反馈时提供版本、渠道和错误，遮住真实资料与密钥。
